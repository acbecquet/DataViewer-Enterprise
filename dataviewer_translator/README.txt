Document Translator - User Guide
=================================

SETUP:
1. You need an Anthropic API key to use this tool
2. Get your key from: https://console.anthropic.com
3. When you first run the app, enter your API key

HOW TO USE:
1. Select target language (English or Chinese)
2. Click "Select Files" to choose Excel or PowerPoint files
3. Click "Translate" to start
4. Translated files will be saved in the same folder with "_translated" suffix

SUPPORTED FILES:
- Excel: .xlsx, .xls
- PowerPoint: .pptx, .ppt

TIPS:
- You can translate multiple files at once
- The app automatically detects source language
- Caching saves money on repeated translations

SUPPORT:
For help, contact: support@your-company.com

API COSTS:
Translation uses Anthropic's Claude API. Typical costs:
- Light use (50 translations/day): ~$10-20/month
- Medium use (200 translations/day): ~$40-60/month
