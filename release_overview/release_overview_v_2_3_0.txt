DataViewer Enterprise - v2.3.0 Release Notes
============================================

AUTO-RECOVERY (the big one)
---------------------------
DataViewer now keeps a continuously-updated, on-disk snapshot of everything you
have open - TPM files, Sensory sessions, and Detailed Sensory sessions -
including edits you have not saved yet.

If the app closes unexpectedly - a crash, or the automatic software update
restarting it - your work is no longer lost:
 - On the next launch, DataViewer asks "N file(s)/session(s) were open when
   DataViewer last closed unexpectedly. Reload them?" Click Yes to restore
   everything exactly as it was, unsaved edits included.
 - Even if you click No, a new Tools -> Recover button lets you reload the
   previous session's items at any time during the session - and choose which
   ones.

CONSOLIDATED SAVE-ON-CLOSE
--------------------------
Closing the app with unsaved work now shows a single "Save All / Discard /
Cancel" prompt listing everything unsaved, instead of silently dropping it.
Save All saves your work (and asks where to put any untitled session file).
This also fixes a gap where Detailed Sensory edits were never offered for
saving on close - they are now saved like everything else.

SETTINGS OUTPUT PATHS APPLY EVERYWHERE
--------------------------------------
The per-mode folders set under Settings (TPM / Sensory / Detailed Sensory) now
act as the default location for EVERY file dialog in that mode - saving,
loading, and creating new files - not just reports.

----------------------------------------------------------------------
No database changes or administrator action are required for this release; the
recovery feature is entirely local to each user's machine.
