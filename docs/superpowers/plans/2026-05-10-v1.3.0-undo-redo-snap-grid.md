# v1.3.0 — Undo/Redo + Snap-to-Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Add undo/redo for layout edits + snap-to-grid with alignment guides to the existing `ReportPreviewDialog`. Ship as one combined v1.3.0 release.

**Architecture:** Phase 4 (undo/redo) lands first — it refactors the 3 existing `m_layout` mutation paths through a `LayoutCommand` stack. Phase 3 (snap/guides) layers on top — it intercepts drag-time `rectChanged` signals before they fire the (now command-wrapped) `applyRectEdit`.

**Scope-correction from original 2026-05-06 plan:**
- Original spec assumed 6+ command types (`MoveItemCommand`, `ResizeItemCommand`, `SortColumnCommand`, `EditTextCommand`, `ToggleSampleCommand`, `ZOrderCommand`). Scout confirms only **3 mutation paths exist today** (`applyRectEdit`, `applyFontSize`, `applySortChange`). v1.3.0 ships 3 command types — one per real mutation site.
- `EditTextCommand` deferred — cover/divider title-text editing was the Phase 7 feature you cut.
- `ToggleSampleCommand` deferred — excluded-samples state is outside `m_layout`, and re-clicking the checkbox is a natural revert.
- `ZOrderCommand` deferred — no Z-order edit surface today.
- Original Task 32's `MoveItemCommand` + `ResizeItemCommand` collapsed into one `RectCommand` since `ResizableSlideItem::rectChanged` emits a full rect (no need to distinguish move from resize at the command layer).
- Original spec assumed a toolbar already existed. It doesn't — Task 6 builds one.

**Tech Stack:** C++17, Qt 6.10.1, namespace `DVE`, qmake/MinGW build, QtTest framework.

#pragma once
#include "ReportLayout.h"
#include <QString>
#include <QRectF>

namespace DVE {

// Abstract command. apply()/undo() mutate the supplied ReportLayout
// in-place. description() is for tooltip / future undo history UI.
class LayoutCommand {
public:
    virtual ~LayoutCommand() = default;
    virtual void apply(ReportLayout&) = 0;
    virtual void undo(ReportLayout&)  = 0;
    virtual QString description() const = 0;
};

// Geometry change (move OR resize — same shape: old/new QRectF).
// Targets one of: cover title/subtitle, divider title, content/cumulative
// title/table/radar/propertiesBox.rect.
class RectCommand : public LayoutCommand {
public:
    RectCommand(const QString& slideKey,
                const QString& elementId,
                const QRectF&  oldRect,
                const QRectF&  newRect);
    void apply(ReportLayout&) override;
    void undo(ReportLayout&)  override;
    QString description() const override;
private:
    void setRect(ReportLayout&, const QRectF&) const;
    QString m_slideKey;
    QString m_elementId;
    QRectF  m_old;
    QRectF  m_new;
};

// Font-size change. Targets cover/divider title, cover subtitle, content/
// cumulative title/table/propertiesBox font.
class FontSizeCommand : public LayoutCommand {
public:
    FontSizeCommand(const QString& slideKey,
                    const QString& elementId,
                    int oldPt,
                    int newPt);
    void apply(ReportLayout&) override;
    void undo(ReportLayout&)  override;
    QString description() const override;
private:
    void setFontPt(ReportLayout&, int) const;
    QString m_slideKey;
    QString m_elementId;
    int     m_old;
    int     m_new;
};

// Table sort change. Mutates ReportLayout::tableSort.
class SortCommand : public LayoutCommand {
public:
    SortCommand(const QString& oldColumn, Qt::SortOrder oldOrder, bool oldEnabled,
                const QString& newColumn, Qt::SortOrder newOrder, bool newEnabled);
    void apply(ReportLayout&) override;
    void undo(ReportLayout&)  override;
    QString description() const override { return QStringLiteral("Sort column"); }
private:
    QString       m_oldCol, m_newCol;
    Qt::SortOrder m_oldOrd, m_newOrd;
    bool          m_oldEnabled, m_newEnabled;
};

} // namespace DVE
```

#include "LayoutCommand.h"

namespace DVE {

// --- RectCommand ----------------------------------------------------------
RectCommand::RectCommand(const QString& slideKey, const QString& elementId,
                         const QRectF& oldRect, const QRectF& newRect)
    : m_slideKey(slideKey), m_elementId(elementId),
      m_old(oldRect), m_new(newRect) {}

void RectCommand::apply(ReportLayout& l) { setRect(l, m_new); }
void RectCommand::undo (ReportLayout& l) { setRect(l, m_old); }

QString RectCommand::description() const {
    return QStringLiteral("Move/resize %1 on %2").arg(m_elementId, m_slideKey);
}

void RectCommand::setRect(ReportLayout& l, const QRectF& r) const {
    if (m_slideKey == QLatin1String("cover")) {
        if      (m_elementId == QLatin1String("title"))    l.coverTitle    = r;
        else if (m_elementId == QLatin1String("subtitle")) l.coverSubtitle = r;
    } else if (m_slideKey.startsWith(QLatin1String("divider_"))) {
        // divider has only title — store the rect, font, and text per-key
        // (existing layout stores rect on coverTitle for dividers? check
        // ReportLayout.h; if it has a dividerRects QHash, use that)
        // PER SCOUT: divider title rect lives at m_layout.dividerTitles[slideKey]
        // — but scout report only mentioned font, not rect. Verify in
        // ReportLayout.h before final wiring; if a separate rect field is
        // missing, this branch falls through and the dialog handles it.
    } else if (m_slideKey == QLatin1String("cumulative")) {
        if      (m_elementId == QLatin1String("title")) l.cumulative.title = r;
        else if (m_elementId == QLatin1String("table")) l.cumulative.table = r;
        else if (m_elementId == QLatin1String("radar")) l.cumulative.radar = r;
        else if (m_elementId == QLatin1String("propertiesBox"))
            l.cumulative.propertiesBox.rect = r;
    } else {
        // content_<sessionId>
        ContentSlideLayout cs = l.contentSlides.value(m_slideKey);
        if      (m_elementId == QLatin1String("title")) cs.title = r;
        else if (m_elementId == QLatin1String("table")) cs.table = r;
        else if (m_elementId == QLatin1String("radar")) cs.radar = r;
        else if (m_elementId == QLatin1String("propertiesBox"))
            cs.propertiesBox.rect = r;
        l.contentSlides[m_slideKey] = cs;
    }
}

// --- FontSizeCommand ------------------------------------------------------
FontSizeCommand::FontSizeCommand(const QString& slideKey, const QString& elementId,
                                 int oldPt, int newPt)
    : m_slideKey(slideKey), m_elementId(elementId), m_old(oldPt), m_new(newPt) {}

void FontSizeCommand::apply(ReportLayout& l) { setFontPt(l, m_new); }
void FontSizeCommand::undo (ReportLayout& l) { setFontPt(l, m_old); }

QString FontSizeCommand::description() const {
    return QStringLiteral("Font %1pt → %2pt on %3").arg(m_old).arg(m_new).arg(m_elementId);
}

void FontSizeCommand::setFontPt(ReportLayout& l, int pt) const {
    if (m_slideKey == QLatin1String("cover")) {
        if      (m_elementId == QLatin1String("title"))    l.coverTitleFontPt    = pt;
        else if (m_elementId == QLatin1String("subtitle")) l.coverSubtitleFontPt = pt;
    } else if (m_slideKey.startsWith(QLatin1String("divider_"))) {
        if (m_elementId == QLatin1String("title"))
            l.dividerTitleFontPts[m_slideKey] = pt;
    } else if (m_slideKey == QLatin1String("cumulative")) {
        if      (m_elementId == QLatin1String("title"))         l.cumulative.titleFontPt         = pt;
        else if (m_elementId == QLatin1String("table"))         l.cumulative.tableFontPt         = pt;
        else if (m_elementId == QLatin1String("propertiesBox")) l.cumulative.propertiesBox.fontPt = pt;
    } else {
        ContentSlideLayout cs = l.contentSlides.value(m_slideKey);
        if      (m_elementId == QLatin1String("title"))         cs.titleFontPt         = pt;
        else if (m_elementId == QLatin1String("table"))         cs.tableFontPt         = pt;
        else if (m_elementId == QLatin1String("propertiesBox")) cs.propertiesBox.fontPt = pt;
        l.contentSlides[m_slideKey] = cs;
    }
}

// --- SortCommand ----------------------------------------------------------
SortCommand::SortCommand(const QString& oldC, Qt::SortOrder oldO, bool oldE,
                         const QString& newC, Qt::SortOrder newO, bool newE)
    : m_oldCol(oldC), m_newCol(newC), m_oldOrd(oldO), m_newOrd(newO),
      m_oldEnabled(oldE), m_newEnabled(newE) {}

void SortCommand::apply(ReportLayout& l) {
    l.tableSort.column  = m_newCol;
    l.tableSort.order   = m_newOrd;
    l.tableSort.enabled = m_newEnabled;
}
void SortCommand::undo(ReportLayout& l) {
    l.tableSort.column  = m_oldCol;
    l.tableSort.order   = m_oldOrd;
    l.tableSort.enabled = m_oldEnabled;
}

} // namespace DVE

void ReportPreviewDialog::pushCommand(QSharedPointer<LayoutCommand> cmd) {
    if (!cmd) return;
    cmd->apply(m_layout);
    m_undoStack.push(cmd);
    if (m_undoStack.size() > kMaxUndoDepth) m_undoStack.removeFirst();
    m_redoStack.clear();
    scheduleAutoSave();
}

void ReportPreviewDialog::doUndo() {
    if (m_undoStack.isEmpty()) return;
    auto cmd = m_undoStack.pop();
    cmd->undo(m_layout);
    m_redoStack.push(cmd);
    populateCanvas();             // re-render after layout mutation
    scheduleAutoSave();
}

void ReportPreviewDialog::doRedo() {
    if (m_redoStack.isEmpty()) return;
    auto cmd = m_redoStack.pop();
    cmd->apply(m_layout);
    m_undoStack.push(cmd);
    populateCanvas();
    scheduleAutoSave();
}
```

void TstLayoutCommand::testStackUndoRedoSequence() {
    // Simulate the dialog's stack: push 3 commands, undo 2, redo 1, verify
    // state matches expected at each step.
    DVE::ReportLayout l;
    DVE::ContentSlideLayout c;
    c.table = QRectF(0, 0, 1, 1);
    l.contentSlides[QStringLiteral("content_0")] = c;

    QStack<QSharedPointer<DVE::LayoutCommand>> undo, redo;
    auto push = [&](QSharedPointer<DVE::LayoutCommand> cmd) {
        cmd->apply(l);
        undo.push(cmd);
        redo.clear();
    };
    auto doUndo = [&]() {
        if (undo.isEmpty()) return;
        auto cmd = undo.pop();
        cmd->undo(l);
        redo.push(cmd);
    };
    auto doRedo = [&]() {
        if (redo.isEmpty()) return;
        auto cmd = redo.pop();
        cmd->apply(l);
        undo.push(cmd);
    };

    push(QSharedPointer<DVE::RectCommand>::create(
        QStringLiteral("content_0"), QStringLiteral("table"),
        QRectF(0, 0, 1, 1), QRectF(2, 2, 2, 2)));
    push(QSharedPointer<DVE::RectCommand>::create(
        QStringLiteral("content_0"), QStringLiteral("table"),
        QRectF(2, 2, 2, 2), QRectF(3, 3, 3, 3)));
    push(QSharedPointer<DVE::RectCommand>::create(
        QStringLiteral("content_0"), QStringLiteral("table"),
        QRectF(3, 3, 3, 3), QRectF(4, 4, 4, 4)));

    QCOMPARE(l.contentSlides.value(QStringLiteral("content_0")).table,

    QCOMPARE(l.contentSlides.value(QStringLiteral("content_0")).table,

- [ ] **Step 2: During drag, scan neighbour edges**

In `mouseMoveEvent`, after computing `target` (from Task 7):
```cpp
// Edge/centerline alignment scan
if (m_snapEnabled && scene()) {
    QRectF selfRect(target.x(), target.y(), m_w, m_h);
    QVector<QLineF> guides;
    constexpr double tolPx = 6.0;   // 0.1" — wider than kGridPx for forgiving alignment

    auto trySnapH = [&](double otherY, double selfY) {
        if (std::abs(otherY - selfY) < tolPx) {
            target.setY(target.y() + (otherY - selfY));
            // emit a horizontal guide spanning the scene width
            QRectF sceneRect = scene()->sceneRect();
            guides.append(QLineF(sceneRect.left(), otherY,
                                 sceneRect.right(), otherY));
        }
    };
    auto trySnapV = [&](double otherX, double selfX) {
        if (std::abs(otherX - selfX) < tolPx) {
            target.setX(target.x() + (otherX - selfX));
            QRectF sceneRect = scene()->sceneRect();
            guides.append(QLineF(otherX, sceneRect.top(),
                                 otherX, sceneRect.bottom()));
        }
    };

    for (auto* it : scene()->items()) {
        if (it == this) continue;
        auto* other = dynamic_cast<ResizableSlideItem*>(it);
        if (!other) continue;
        QRectF o = other->sceneBoundingRect();
        // top edges, bottom edges, center-y
        trySnapH(o.top(),    selfRect.top());
        trySnapH(o.bottom(), selfRect.bottom());
        trySnapH(o.center().y(), selfRect.center().y());
        // left/right edges + center-x
        trySnapV(o.left(),   selfRect.left());
        trySnapV(o.right(),  selfRect.right());
        trySnapV(o.center().x(), selfRect.center().x());
    }
    // Slide centerlines too (scene center)
    QRectF sr = scene()->sceneRect();
    trySnapH(sr.center().y(), selfRect.center().y());
    trySnapV(sr.center().x(), selfRect.center().x());

    setPos(target);
    if (!guides.isEmpty())  emit alignmentGuideRequested(guides);
    else                    emit alignmentGuidesCleared();
} else {
    setPos(target);
}
```

    clearAlignmentGuides();

    pen.setStyle(Qt::DashLine);

    for (const QLineF& l : guides) {
