# v2.8 Phase 1 - Quick Wins (DV-19, DV-20, DV-24) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the three Phase 1 quick wins - DV-19 (heating-tech dropdown variants + resistance seeding), DV-20 (thicker/darker sensory radar dashed rings), DV-24 (report-slide titles 2 pt smaller) - with zero regressions.

**Architecture:** DV-19 centralizes the quadruplicated tech-to-resistance-offset logic into one header helper (`src/pipeline/HeatingTech.h`), unit-tests it, wires the four call sites to it, then adds the new dropdown items plus a user-selection handler that seeds the resistance field. DV-20 is a two-value pen tweak in `RadarChartWidget::drawGrid`. DV-24 sets the existing `ReportLayout` title-size constants 2 pt smaller and wires `PptxWriter` (which currently hardcodes the sizes) to consume them, so the export derives from one tested source of truth.

**Tech Stack:** C++17, Qt 6.10.1 Widgets/Test, qmake + MinGW 13.1.0, `-Werror -Wall -Wextra`. Header-only helper for testability. Qt Test suites under `tests/`.

- [ ] **Step 4: Create the helper**

Create `src/pipeline/HeatingTech.h`:

```cpp
#pragma once
#include <QString>

namespace DVE {

// Resistance offset (ohms) added in the power formula P = V^2 / (R + offset),
// keyed by heating technology. Matches the Excel SWITCH formula. S17B/S25B/S25B1
// are specific T58G variants (DV-19) and share its 0.78 offset. Single source of
// truth - all power-calc sites call this instead of inlining the branch.
inline double heatingTechResistanceOffset(const QString& tech)
{
    const QString t = tech.trimmed().toUpper();
    if (t == QLatin1String("CCELL3.0") || t == QLatin1String("CCELL 3.0")
        || t == QLatin1String("T58G")  || t == QLatin1String("S17B")
        || t == QLatin1String("S25B")  || t == QLatin1String("S25B1"))
        return 0.78;
    if (t == QLatin1String("T51"))
        return 0.25;
    return 0.0;
}

// Default resistance (ohms) seeded when the user picks a T58G variant from the
// heating-technology dropdown (DV-19). Editable afterwards. Returns true and sets
// `out` for a known variant; returns false and leaves `out` untouched otherwise.
inline bool heatingTechDefaultResistance(const QString& tech, double& out)
{
    const QString t = tech.trimmed().toUpper();
    if (t == QLatin1String("S17B"))  { out = 1.3; return true; }
    if (t == QLatin1String("S25B"))  { out = 1.1; return true; }
    if (t == QLatin1String("S25B1")) { out = 1.0; return true; }
    return false;
}

} // namespace DVE
```
