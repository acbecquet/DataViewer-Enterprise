## Learnings

- **Active-card selection needs CONTAINER click-focus.** `onAppFocusChanged` only fires on a Qt focus change; child labels/empty `QGroupBox` area are `NoFocus`, so a click there never moved focus and `m_focusedCard` stayed stale (Space hit only the first sample). Fix = `SampleCard` `Qt::ClickFocus` + `mousePressEvent`->`setFocus`. (lessons.md 2026-06-25.)
- **A key-capture dialog that BINDS Space/Enter must use `NoFocus` buttons** so key events reach the dialog's event filter; confirm by mouse only.
- **Phone-append data-safety is enforced in `tryWriteSensoryCore`'s read-merge-write** (`DatabaseManager.cpp` ~1781-1799): it merges DB truth into the wholesale blob and adopts the fresh version, so the 3-line merge-tail fix protects EVERY whole-session save. `scenario10` proves it end-to-end. The card-grow helper `appendDbOnlyTailSamples` is SHARED by the panel and the e2e (anti-drift, same pattern as `overlayMergedScores`/scenario9).
- **Postgres least-privilege GOTCHA (verified):** `REVOKE EXECUTE ON FUNCTION f FROM <role>` does NOT deny the role — functions default to PUBLIC EXECUTE and every role is a PUBLIC member. Must `REVOKE ... FROM PUBLIC` (schema owner keeps it). `has_function_privilege` is the catalog-level oracle (a direct call can hit overload-ambiguity before the permission check, since the 6-arg `dve_commit_cell` has a default making a 5-arg call ambiguous).
- **MIP on this machine labels `.py` (and sometimes `.md/.txt`) to ciphertext at rest** even when written via Python. Commit PLAINTEXT by rewrite-then-`git add` in ONE command; verify with `git show HEAD:<path> | head`. The `.sql/.html/.yml` written this session stayed plaintext. `tools/decrypt_via_copy.py` covers `src/tests/tools` only — NOT `deploy/`.
- **Workflow agents that write code need the explicit Python-write instruction AND the orchestrator must re-plaintext before commit** — the impl agents' `.py` still landed as ciphertext (read them via the allowlisted Python, not the Read tool, to review). A `| tail`/PowerShell-`>` pipe BUFFERS — redirect background build/test output to a file and read it, or wait for the task-completion notification.
